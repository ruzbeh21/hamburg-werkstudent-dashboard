So funktioniert's

Eine kleine Daten-Pipeline in Python, die täglich per GitHub Actions laufen kann.

  1. APIJobsuche der Bundesagentur für Arbeit, 6 Suchbegriffe, Hamburg + 25 km
  2. Roh-JSONLokal zwischengespeichert, mit Zeitstempel, nicht im Repo
  3. BereinigungDuplikate, Firmennamen, Stunden, Remote, Kontaktdaten entfernt
  4. SQLiteTabellen postings, skills, posting_skills, runs
  5. SQL-AbfragenEine Datei je Kennzahl im Ordner queries/
  6. DashboardStatische Seite auf GitHub Pages, liest kleine JSON-Dateien
